# Описание бота
## Для успешного старта необходимо:

Создать файл 
```py
Settings.py
```
В файл добавить такие строчки:
```py
token = '' #Токен бота в ТГ
file_bd = 'movies.db' #Название базы данных
XAPIKEY = '' #Апи ключ для сайта https://kinopoisk.dev/
```
Команда /drop служит очисткой  истории оценки фильмов у пользователя
